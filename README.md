# Kestrel Market Intelligence

An agentic AI platform for analyzing energy markets using
real-time market data, weather, news and domain knowledge.

## Project Status

In Development

## Overview

Kestrel is a multi-agent market intelligence system designed
to combine structured market data with unstructured information
to generate explainable market analysis.

The system is being built around:

- Python / FastAPI
- LangGraph
- LangChain
- PostgreSQL + pgvector
- Next.js
- Gemini
- RAG
- Ragas / LLM evaluation
